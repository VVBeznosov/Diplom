# Инструкция по запуску обновления конфигурации 1С

## 1. Добавление элементов в справочник "Номенклатура"

### Действия

1. Перейдите в меню: **"Покупка и продажа"** → **"Справочники"**. Откройте справочник **"Номенклатура"**
2. Нажмите кнопку **"Создать"**
3. Создайте элемент:
   - **Наименование:** `Абонентское обслуживание`
4. Нажмите кнопку **"Создать"** еще раз
5. Создайте элемент:
   - **Наименование:** `Почасовая работа специалиста`
6. **Запишите** оба элемента

## 2. Настройка констант

### Действия

1. Перейдите в меню: **"Администрирование"** → **"Сервис"** → **"Форма констант"**
2. Найдите и заполните поля:

| Поле                                    | Значение                                |
|-----------------------------------------|-----------------------------------------|
| **Номенклатура абонентская плата**      | Выберите "Абонентское обслуживание"     |
| **Номенклатура работы специалиста**     | Выберите "Почасовая работа специалиста" |
| **Токен управления телеграм-ботом**     | Введите данные зарегистрированного бота |
| **Идентификатор группы для оповещения** | Введите идентификатор группы Telegram   |

3. Нажмите **"Записать"** для сохранения констант

## 3. Настройка ролей пользователей

### Роль "Менеджер" и "Специалист"

**Для работы с документами "Обслуживание клиентов":**

1. Откройте **"Администрирование"** → **"Настройка пользователей и прав"** → **"Пользователи"**
2. Выберите нужного пользователя
3. На вкладке **"Права доступа"** выбрать нужный профиль
4. Установите:
   - `Менеджер` - для менеджеров
   - `Специалист` - для специалистов
5. **"Записать и закрыть"**

*Примечание:* Роли "Специалист" также доступен **"Отчёт по выработке специалистов"**

### Роль "БухгалтерИТФирмы"

**Для массового создания документов "Реализация товаров и услуг":**

1. В настройках пользователя (см. выше) добавьте профиль:
   - `БухгалтерИТФирмы`
2. Этому сотруднику будет доступен отчет:
   - **"Анализ выставленных актов"**

### Роль "КадровикРасчетчик"

**Для работы с заработной платой и отпусками:**

1. В настройках ролей пользователя добавьте роль:
   - `КадровикРасчетчик`

**Доступные возможности для этой роли:**

- Ввод графиков работы и отпусков
- Условия оплаты сотрудников (оклады и процент оплаты)
- Работа с документами:
  - "Начисление Заработной Платы"
  - "Начисление Фиксированных Премий"
  - "Выплата Зарплаты"
- Доступ к отчетам:
  - Отчеты по зарплате
  - Отчеты по отпускам
  - Отчеты по выработке специалистов

## 4. Проверка работы обновления

После выполнения всех настроек рекомендуется:

1. Перезапустить информационную базу
2. Проверить доступность новых функций для соответствующих ролей
3. Убедиться, что документы создаются корректно
4. Проверить работу отчетов

## Важные примечания

- Все изменения прав доступа вступают в силу после **перезапуска сеанса** пользователя
- Рекомендуется выполнять настройки в период минимальной нагрузки на базу
- Сделайте резервную копию базы данных перед внесением масштабных изменений
